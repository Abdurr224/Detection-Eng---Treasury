Dashboard Tracking
Designed for client and secops utilisation 

Sign-in Activity Monitoring

  - Sign-in success and failure events per user

  - Device trust status (corporate-managed vs personal devices)

  - Authentication method used (single-factor vs multi-factor)

  - Conditional Access policy outcomes

  - User's registered location compared against the IP location in a sign-in

  - Per user historical sign-in usage from ASN’s.

  - Flagging of users with known leaked credentials.

  - User context including department and job title.

Group Membership Tracking

  - Timeline of member additions and removals

  - Who initiated each change and from which IP address

  - Volume of changes made by each initiator

  - Department breakdown and distribution of current group members

Alert Tracking
- Raw and graphical alert tracking showing TP,BP,FP distribution


The dashboard is tabbed per Treasury App, containing application sign in activity and group modification activity. The dashboard presented reflects how all the tab pages look.
